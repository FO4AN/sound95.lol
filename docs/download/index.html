Download Sound95

The latest version is Sound95 v0.4.0

Sound95 runs on Windows and Linux PCs, and there's no phone or macOS version right now. Open this page on your computer to install it.

Sound95 for Windows
Windows 10 or 11, 64-bit
Download Installer
Sound95_x64-setup.exe from GitHub Releases
  1. Run the file. It installs for your user only, so it doesn't need administrator rights.
  2. If SmartScreen warns you, choose More info, then Run anyway. The installer isn't code signed yet.
  3. Open Sound95 and click Log In.

Sound95 for Linux
x86-64, no root needed
curl -fsSL https://github.com/FO4AN/sound95/releases/latest/download/install-linux.sh | bash
  1. Paste that into a terminal. It installs the app and a menu entry for your user. You can read the script first.
  2. Open Sound95 from your app menu and click Log In.

Updates

Sound95 checks for a new version when it starts and every six hours. When there is one, a notice appears above the taskbar: Details shows what changed, and Update Now installs it and restarts the app. Help, Check for Updates does the same on demand. Releases are signed, and an update that doesn't match the key built into the app is refused.
